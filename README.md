Este repositório reúne meus estudos para a certificação **Microsoft Certified: Azure Data Fundamentals (DP-900)**.

O objetivo é consolidar os principais conceitos de dados, serviços do Microsoft Azure e materiais utilizados durante minha preparação.

Em **julho de 2026**, concluí minha preparação e obtive a certificação **Microsoft Certified: Azure Data Fundamentals (DP-900)**.

---

## 📚 Como organizei meus estudos

Antes de organizar o conteúdo no GitHub, utilizei o **Notion** para registrar anotações, dúvidas, revisões e acompanhar os módulos por meio de um Kanban.

Meu fluxo de estudo foi:

```text
📖 Microsoft Learn
        ↓
🎥 Vídeos complementares
        ↓
📝 Anotações no Notion
        ↓
❓ Revisão
        ↓
🧪 Simulados
        ↓
📂 Organização no GitHub
```

Essa organização me ajudou a acompanhar o progresso e identificar quais assuntos precisavam de mais revisão.
